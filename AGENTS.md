# Repository conventions

For project context or cluster migration, first read
[`docs/PROJECT_HANDOFF.md`](docs/PROJECT_HANDOFF.md). It records current decisions,
data sources, model selection, validation limits, and the paper/code alignment.
Check its date and the latest repository changes before treating it as current.

Write concise, idiomatic English in authored code, comments, docstrings, prompts,
CLI help, UI text, documentation, and generated descriptions.

Preserve recorded trajectory events, task materials, and external quotations
verbatim. Their original language is part of the evidence.

Keep verification records minimal. Store original events once and use IDs to
link check rounds, context, edits, and rechecks.

# Autonomous work

Proceed with routine reading, searching, file creation, reversible edits, builds,
tests, and task-related network access without repeated confirmation when
platform permissions allow it.

Before deleting files or directories, discarding work, irreversibly overwriting
user data, or rewriting shared history, explain the specific impact and obtain
explicit confirmation. Respect platform approval requirements.
